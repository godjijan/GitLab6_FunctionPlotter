# Анализатор графиков функций

Учебное приложение с графическим интерфейсом для построения и сравнения математических функций.

## Возможности

- построение тригонометрических, линейных, квадратичных, экспоненциальных и логарифмических функций;
- поиск точек пересечения методом сканирования и деления пополам;
- настройка границ координатной области;
- временное скрытие отдельных графиков;
- сохранение результата в PNG;
- проверка введённых параметров.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python lab6_graf.py
```

Требуется Python 3.10 или новее. Библиотека `tkinter` входит в стандартную поставку Python для Windows.
